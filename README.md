# Jetpack Compose Tutorial: From Zero to Pro

Complete source code for the [Jetpack Compose Tutorial](https://kemalcodes.com/jetpack-compose-tutorial/) series on [kemalcodes.com](https://kemalcodes.com).

A step-by-step Android tutorial that takes you from your first Composable to building and publishing a real app. 25 tutorials with working code you can clone and run.

## How to Use This Repo

Each tutorial has its own branch. Switch to the branch you want:

```bash
git clone https://github.com/kemalcodes/android-jetpack-compose-tutorial.git
cd android-jetpack-compose-tutorial

# Switch to a specific tutorial
git checkout tutorial-01-what-is-compose
```

The `main` branch contains the base project. Tutorial branches build on top of it.

## Tech Stack

- **Kotlin** — primary language
- **Jetpack Compose** — UI toolkit
- **Material 3** — design system
- **Android Studio** — IDE
- **Minimum SDK:** API 24 (Android 7.0)

## Requirements

- [Android Studio](https://developer.android.com/studio) (latest stable version)
- JDK 17+
- An Android device or emulator

## Run the Project

1. Clone the repo
2. Open in Android Studio
3. Switch to the tutorial branch you want
4. Click Run
